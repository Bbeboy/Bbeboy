I build apps and storefronts for Shopify and Tiendanube: custom apps, headless stores with Hydrogen and React Router, and the API integrations that hold everything together. Based in Mexico, currently in my 7th semester of Computer Science. The username is a nickname my friends gave me years ago, and it stuck.

### What I'm working on

- I lead a small team building apps for Shopify and Tiendanube from scratch: backend in Node.js, app logic, frontend in React, CI/CD, and the architecture behind it all. I also review my teammates' PRs before anything ships.
- I maintain two production headless storefronts built with Shopify Hydrogen on React Router. When one of them needs Klaviyo, tracking pixels, reviews or bundles, I integrate it directly against the app's HTTP API, because there's no theme to install plugins into.
- I've taken full websites from design to deploy, frontend end to end, connected to external services over REST and GraphQL.
- I've migrated entire stores between platforms: products, inventory, customers, orders. Mass migrations break in ways the docs never mention.
- Right now I'm finishing a mobile app that consumes the Shopify Storefront GraphQL API. A small headless build, and it's close to shipping.
